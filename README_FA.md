# PULSE Bot V1

MVP واقعی بات اتوماسیون PULSE: دریافت لید، ساخت پروفایل، پیشنهاد اولیه PLUS/PRO/360 و اطلاع‌رسانی به ادمین.

## راه‌اندازی
1. در تلگرام به @BotFather برو و `/newbot` را اجرا کن.
2. Token را بگیر و در متغیر `BOT_TOKEN` قرار بده.
3. Python 3.10+ نصب باشد.
4. اجرا: `pip install -r requirements.txt` سپس `python bot.py`
5. داخل بات `/id` را بفرست تا Chat ID خودت را ببینی و آن را در `ADMIN_CHAT_IDS` قرار بده.

برای چند ادمین: `ADMIN_CHAT_IDS=123,456`

## مهم
Token را با هیچ‌کس به اشتراک نگذار.
محتوای پکیج‌ها و قیمت‌ها عمداً placeholder هستند و قبل از استفاده تجاری باید با پیشنهاد نهایی PULSE جایگزین شوند.

## جریان
/start → فرم → پروفایل → Recommendation Engine → پیشنهاد پکیج → درخواست تماس → اطلاع تیم
